教师请假管理系统  使用说明
================================================

一、这是什么
------------------------------------------------
一个只在您这台电脑上运行的教师请假登记工具。不联网、不登录、
不上传任何数据，所有记录都存在本文件夹里。

主要用途：
  1. 登记教师请假（事假、病假、公假等），可区分学校、学科、年级
  2. 一屏查看全部记录，可筛选、可导出 Excel
  3. 按教师查看个人档案：累计请假次数与天数、类型分布、
     历年明细，姓名 + 学校视为同一位教师
  4. 首页会把还没销假的请假列出来：
     ① 已到结束日期还没销假的（按超期天数标红/标黄，优先处理）
     ② 结束日期未定、已经请了很久还没销假的
     ③ 还没结束的（正在休、还没开始），单独一组，只显示还剩几天


二、怎么打开
------------------------------------------------
双击本文件夹里的「教师请假系统.exe」即可。

第一次打开可能需要几秒钟，属正常现象。
如果 Windows 弹出「已保护你的电脑」提示，点「更多信息」，
再点「仍要运行」。这是因为软件没有购买微软的数字签名证书，
不是病毒。本软件不联网，可放心使用。


三、新增请假怎么填
------------------------------------------------
点右上角「新增请假」，按顺序填：

  学校      下拉选，选项在「设置 → 学校」里维护。
            先选学校：教师姓名的下拉候选只列这所学校的老师，
            不会把别的学校的人混进来。
            默认会带出你上一次录入时用的学校/学科/年级/类型，
            连着录同一个学校的人时不用每次重选
  教师姓名  直接输入。本校输入过的姓名会自动补全，
            并自动带出这个人上次的学科、年级、电话
            （学校不会被自动改动，始终以您选的为准；
            你自己改过的学科/年级不会被覆盖）
  学科      下拉选，选项在「设置 → 学科与年级」里维护
  年级      下拉选，不确定时可选「不指定」
  请假类型  事假、病假、公假等，可在设置里增删
  开始日期  必填，配合「开始时段」选上午或下午
  结束日期  分两种情况（见下）
  请假天数  自动算，不用手填

关于结束日期的两种情况：

  ◆ 知道哪天回来（大多数情况）
    直接选结束日期和结束时段，系统按自然日自动计算天数。

  ◆ 不知道哪天回来（如住院、突发急事）
    勾选「结束日期未定」。此时结束日期会变灰不用填，
    天数从开始那天起按今天实时累计，每天打开都会自动加。
    等教师返校后点「销假」，系统按销假当天结算总天数。

  ◆ 时段冲突不允许保存
    同一位教师（姓名 + 学校都相同）的请假时段不能交叉。
    如果新填的日期和已有的某次请假撞上了，点「保存」不会成功，
    弹窗顶部会出现一条红色提示，列出撞上的是哪几条记录
    （区间、类型、天数、流水号），按提示改日期即可。
    需要分段登记时请利用半天：同一天「上午」和「下午」不算重叠，
    可以分别记成两条（例如上午事假、下午病假）。
    如果撞上的是一条「结束日期未定、还没销假」的记录，红色提示里会
    单独说明：这条会一直占着时间，先给它销假（或补上实际结束日期）
    再录新的请假就可以了。
    之前那条如果录错了，先到「数据总览」或这位教师的档案里改掉它。

  ◆ 同一位老师的新一次请假
    姓名下方会显示「本校已有 N 条记录 · 最近 X 月 X 日 病假」，
    保存时弹窗再确认一次：是新一次请假就点「继续保存」，
    是姓名打错就点「取消」返回修改。

  ◆ 同名的另一位老师
    同名但不在同一所学校，系统当作两个人，互不影响，
    也不会报时段冲突。姓名下方会提示「在某校有记录，
    当前学校还没有」，提醒您确认学校有没有选错。

  ◆ 补录以前的请假，或录入时就已经销假了
    新增 / 编辑窗口下方有一个「已销假」勾选框，勾上后这条记录
    保存时直接记为已销假（不会出现在首页的未销假提醒里），
    适合事后补录历史记录、或老师已经返校销假才来登记的场合。
    编辑一条已销假的记录时这个勾选框是勾上的；
    取消勾选再保存，就等于撤销销假，记录会重新进入待销假。
    注意：「结束日期未定」和「已销假」不能同时勾——
    返校日期都不知道，就谈不上销假。勾了未定，这一项会变灰。


四、四个页面怎么用
------------------------------------------------
【首页】
  · 刚装好、一条记录都没有时，首页顶部会显示「三步就能开始用」的
    引导卡片：加学校 → 录第一条请假 → 到期提醒。点里面的按钮
    直接跳到对应位置，用完这张卡片会自动收起
  · 顶部三个数字：本月请假人次、当前在假人数、待销假人数
  · 未销假提醒：分红黄两组。
      红色 = 已结束满 3 天，或结束日期未定已请满 14 天
      黄色 = 已结束满 1 天，或结束日期未定已请满 7 天
    天数可在「设置 → 提醒阈值」里改。
      - 点卡片右下角「销假」会先弹确认框，写清是哪位老师、哪一段
        请假、共几天，确认后才销假（点「取消」什么都不变），
        避免名字相近时销错了人
      - 点卡片其他地方（姓名、区间、空白处）＝打开这条记录查看/编辑
      - 右上角四个条件可叠加筛选：学校、请假类型、
        紧急程度（超期较久 / 待跟进 / 今日到期）、姓名搜索
      - 人数标签会显示「筛出的 / 全部」，如 3 / 12 条
      - 筛空了会提示「当前筛选下没有待销假记录」，并可一键清除筛选
  · 今日在假：今天正在请假的教师名单，按学校分块显示，
    人多时也能一眼看清。
      - 右上角「全部学校」「全部学科」可缩小范围
      - 「按学校分组 / 按学科分组 / 不分组」切换排列方式
      - 右侧搜索框可输入姓名快速定位
      - 人数标签会显示「筛出的 / 全部」，如 4 / 12 人
      - 点任意一位教师的小卡片，可直接打开编辑窗口
    结束日期未定的会显示「累计」字样，天数为当天累计值。

  请假区间的写法（起止的上午/下午都会标出来）：
     10-19 上午 → 10-23 下午  跨天请假
     10-25 下午 → 10-27 上午  首尾是半天，一眼看得出
     10-26 全天              同一天，整日（上午到下午）
     10-26 上午 / 10-26 下午  同一天，只请半天
     10-01 上午 → 未定        结束日期未定
    鼠标停在上面可以看到带年份的完整日期。


【数据总览】
  · 可按学校、姓名、学科、类型、状态、日期区间、是否代课组合筛选
  · 点表头「教师姓名 / 学校 / 请假区间 / 天数 / 状态」可排序
  · 天数后面带「累计」小标签的，是结束日期未定的记录，
    数字为当天累计值
  · 每行右侧：销假、编辑、删除
    删除会把这 1 条记录从数据里彻底移除（弹窗里会写清是谁、哪一段、
    共几天），删前程序会自动备份一份，万一删错可到设置里恢复
  · 点「教师姓名」可直接跳到该教师的档案页，看他的全部请假
  · 右下角「导出 Excel」：只导出当前筛选出来的记录
  · 右下角可翻页，每页 20 / 50 / 100 条可选

【教师档案】
  · 同一位教师以「姓名 + 学校」识别：改了校名会被当作另一位教师
  · 一屏一位教师一张卡片，显示累计天数、请假次数、最近一次和当前状态
    （正在请假 / 待销假 / 已销假）
  · 顶部筛选可叠加：
      - 学校、学科
      - 统计范围：全部时间 / 本学期 / 本学年 / 本月，
        也可以直接填「从 / 至」两个日期自己定
      - 当前状态：全部教师 / 正在请假 / 有待销假 / 已全部销假
      - 教师姓名模糊搜索
      - 排序：累计天数最多 / 请假次数最多 / 最近请假在前 / 按姓名
  · 点卡片进入这位教师的详情：
      - 顶部四个数字：累计次数、累计天数、平均每次、最近一次
      - 请假类型分布（按天数，彩色条 + 图例）
      - 按年份统计：每年请了几次、几天
      - 下方「请假明细」列出他的全部记录，可直接销假、撤销销假、编辑、
        删除单条记录（只删这一条，其他记录和这位教师都还在）
    统计范围只影响卡片和详情里的数字，不影响"正在请假"的标记。

  · 请假明细可以筛选和翻页（记录多时很好用）：
      - 右上角三个条件：年份、类型、状态（请假中/待销假/已销假/已撤销）
      - 标题行会显示「筛出 N 条」，筛过的还能一键「清除筛选」
      - 底部可翻页，每页 10 / 20 / 50 条可选
      - 每一位教师各自记住自己的筛选，换人时会自动复位

  · 筛选也会同时改变上面的统计（v1.6 起）
      - 选了年份 / 类型 / 状态后，四个数字和类型分布、按年份统计
        都只按筛出来的这些记录算，标签会变成「筛选内请假」「筛选内天数」
      - 统计区上方会显示一条提示：「下方统计按当前筛选计算：N 条记录」，
        点旁边的「改为按全部记录统计」即可恢复
      - 举例：想看某位老师 2026 年病假一共几天，选年份 2026 + 类型 病假，
        四个数字立刻就是这个组合的结果
      - 右上角的「正在请假 / 待销假」标签始终看全部记录，
        不会被筛选影响（否则选了个旧年份，还在请假的老师会显示成已销假）

  · 右上角「导出 Excel」：只导出当前筛选出来的记录
      - 明细页顶部写着这位教师的姓名、学校、学科、年级、电话
      - 第二个工作表「教师汇总」：累计次数、累计天数、平均每次、
        最近一次、当前状态，外加按请假类型和按年份的分布与占比
      - 文件名自动带上教师姓名，如「张三_请假明细_20261028.xlsx」
      - 没筛选时导出的是这位教师的全部记录

  · 右上角三个按钮：
      - 「← 返回教师列表」
      - 「＋ 为这位教师新增请假」：直接打开新增窗口，学校、姓名、学科、
        年级、电话都已经填好，只需要选请假类型和日期，
        不会点错人、也不会记到别的学校去
      - 「删除这位教师」：破坏性操作，会弹窗列出将要删掉的每一条记录，
        确认后这位教师（姓名 + 学校）名下的全部请假记录一并删除，
        删完回到教师列表。删除前程序会自动备份一份，删错了可以到
        「设置 → 数据与备份」里恢复。只想删掉其中几条记录时，
        点进这位教师的档案，在「请假明细」里逐条删除即可。

  · 在「数据总览」点姓名，也会直接进到同一位教师的详情。

【设置】
  · 提醒阈值：固定结束日期、结束日期未定各有一套黄红阈值
  · 学校：增删学校名称。标签后面的数字表示有几条请假记录在用，
    正在使用的学校不能删除（删除按钮是灰的），需先把这些记录的
    学校改到别的学校，再回来删。
    如果某条记录的学校不在列表里（例如换了学校、或从旧版本带过来），
    这个学校会以虚线标签显示在后面，点后面的「+」就能补进列表。
    录入时如果学校下拉是空的，保存按钮会锁住并提示先去添加学校。
  · 请假类型：可增删。已被记录使用的类型删除时会先确认一次，
    删除后历史记录的原类型名称不会改变
  · 学科与年级：录入时下拉框里的选项，可随时增删
  · 数据与备份：显示记录条数、数据文件大小、备份占用空间，
    可调备份保留份数、立即备份、打开文件夹、从备份恢复。
    下方的备份列表里，每一份都标着「手动备份 / 自动备份 / 恢复前自动备份」，
    并写明里面有多少条记录、哪些教师，恢复前照着条数核对就不会挑错


五、导出的 Excel 有什么
------------------------------------------------
数据总览的「导出 Excel」导出全部（或当前筛选的）记录，两个工作表：

  请假明细  一行一条记录，含学校、学科、年级、起止日期、
            天数、状态、销假时间等。日期是真正的日期格式，
            可以直接在 Excel 里排序、筛选；天数是数值，可以求和。
            结束日期未定的记录，「结束日期」列写「未定」，
            天数为导出当天的累计值。

  汇总统计  按学校、按教师、按请假类型、按学科四种汇总，
            各含人次与合计天数。

教师档案里点「导出 Excel」，导出的是这一位教师（当前筛选的）记录，
表头写清姓名、学校、学科、年级、电话，第二个工作表换成「教师汇总」：

  教师信息  姓名、学校、学科、年级、联系电话、当前状态
  累计统计  累计次数、累计天数、平均每次、最近一次，
            以及全部记录条数与其中已撤销的条数
  分布      按请假类型、按年份的次数 / 天数 / 占比

导出文件的第一行会写明导出时间和当时的筛选条件，
方便存档时说明这份表是怎么筛出来的。


六、数据存在哪里
------------------------------------------------
就在本文件夹的 data 子文件夹里：

  data\leaves.json      全部请假记录（纯文本，可用记事本打开查看）
  data\settings.json    提醒阈值、学校、学科、年级、请假类型等设置
  data\backups\         备份（自动备份 + 手动备份）

每次保存记录前，程序会自动先备份一份；备份数量超过「保留份数」
（默认 30 份，可在设置里改成 10～100 份）后，自动删掉最早的自动备份。

手动点「立即备份一份」生成的那份会单独统计：自动备份超过份数时
被清掉的是自动备份，手动备份按同样的份数另外保留，不会被挤掉。

所以这两块都不会一直变大：

  · 请假记录本身很小，一条约 0.3 KB。
    一学期录 500 条，数据文件大约 150 KB；
    就算录满 1 万条，也只有 3 MB 左右。
  · 备份是数据文件的完整副本，自动备份最多留 30 份（可改），
    手动备份另外留 30 份，总量约为数据文件的 60 倍封顶（现在几 MB 的量级）。
  「设置 → 数据与备份」里能直接看到当前的实际占用。


七、换电脑 / 备份怎么做
------------------------------------------------
把整个「教师请假系统」文件夹（连同 exe 和 data 一起）
复制到 U 盘或另一台电脑，双击 exe 就能继续用，数据完整保留。

建议每周把整个文件夹复制一份到 U 盘或网盘作为备份。

注意：
  · 文件夹可以放在桌面、D 盘、U 盘、中文路径下，都能正常运行
  · U 盘使用中不要直接拔出，先关闭程序
  · 两台电脑各存各的数据，不会自动同步。
    如果要合并，请只在一台电脑上录，另一台用同一份 data 文件夹


八、快捷键
------------------------------------------------
  Ctrl + N       新增请假
  Ctrl + S       保存当前表单（Ctrl + 回车 也可以）
  Esc            关闭当前弹窗

  关闭新增/编辑窗口时，如果已经填了内容还没保存，
  会先问一句「还没保存，确定关闭？」——点遮罩、按 Esc、
  点右上角 × 都一样，手滑不会把填了一半的记录弄丢。
  编辑窗口的左下角还有一个「删除这条记录」，直接删掉当前这条，
  不必先关窗再回列表里找。


九、常见问题
------------------------------------------------
Q：请假天数怎么算？
A：按自然日计算，含周末。上午起算、下午结束各算半天。
   例：10月20日上午 到 10月22日下午 = 3 天。
   同一天「上午→上午」或「下午→下午」= 0.5 天。

Q：结束日期未定的请假，天数会不会算错？
A：不会。它每天按「开始日 → 今天」重新算，所以数字会一天天变大，
   直到销假为止。销假时按销假当天结算并固定下来。
   如果实际返校不是销假那天，先点「编辑」改准结束日期再销假。

Q：为什么首页一直提醒某人？
A：说明该教师还没销假。点「销假」即可消除。
   如果点错了，在数据总览里点「撤销销假」可以改回来。
   结束日期未定的记录，撤销销假后会恢复成未定状态。

Q：学校 / 学科 / 年级下拉里没有我要的选项？
A：到「设置」里对应的地方添加即可，加完立刻生效。
   如果学校下拉整个是空的，说明设置里的学校被删光了，
   此时「新增请假」的保存按钮是灰的，按提示去「设置 → 学校」添加
   一所学校即可，添加后按钮立刻恢复。
   学校是必填项：下拉里选不中（显示「请选择学校」）时，
   点保存会把这一栏标红并提示，不会存成一条没有学校的记录。

Q：数据文件和备份会不会越用越大？
A：不会失控。
   · 记录只是纯文本，一条约 0.3 KB，一学期几百条约 100～200 KB。
   · 备份在每次保存前自动生成，只保留最近 30 份（可改），
     多的会自动删掉，所以备份总量最多是数据文件的 30 倍。
   实际占用在「设置 → 数据与备份」里能看到，一般是几 MB 以内。
   如果常年累积的记录很多，可以按学期导出 Excel 存档，
   再把不需要的旧记录删掉（数据总览或教师档案里点「删除」）。

Q：设置里某个学校的 × 是灰的，点不动？
A：说明还有请假记录在用这所学校。标签后面括号里的数字就是条数。
   如果这所学校确实不用了，先把这些记录的学校改成别的（在数据总览
   里逐条「编辑」），数字变成 0 后就能删了。
   这样设计是为了避免记录里存着一个已经不存在的学校。

Q：同一个人能录两次重叠的请假吗？
A：不能。同一位教师（姓名 + 学校都相同）的请假时段不允许重叠，
   点「保存」会失败，弹窗顶部列出撞上的是哪几条记录。
   如果确实需要分段记录，请把日期改成不重叠的两段
   （同一天上午走、下午回这种半天分段是可以的）。
   注意：结束日期未定的记录会一直占着时间段，
   所以再给它录新请假时一定会提示重叠，这是正常的——
   先销假、或先把它改成具体的结束日期再录。

Q：系统提示「该教师已有记录」，是不是不能录了？
A：可以录。这个提示只是帮您确认没有把姓名打错、也确认不是重复
   登记。如果确实是这位老师的新一次请假，点「继续保存」就行。

Q：从备份恢复以后，怎么不是我删除之前的数据？
A：多半是挑到了「自动备份」，而不是删除前的那一刻。
   自动备份是每次保存前留的快照，所以最新的一条常常正好是
   「刚删掉一位老师之后」的状态，看着就像没恢复成功。
   挑的时候看每行后面写的条数：删除前 5 条、删除后剩 2 条，
   就选写着「5 条记录」的那一行，或者直接选标着「手动备份」的那份
   （手动备份是自己点「立即备份一份」留下的，不会随后被清掉）。
   恢复错了也不要紧：恢复前程序会自动存一份「恢复前自动备份」，
   再对那一份点恢复就能回到恢复之前。

Q：数据会不会丢？
A：每次保存都会先在 data\backups 里留一份。万一文件损坏，
   程序启动时会提示，可直接从备份恢复。

Q：换显示器字太小/太大？
A：按 Ctrl + 加号 或 Ctrl + 减号 可缩放界面。
