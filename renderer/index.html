数据文件夹

每次保存记录前会自动备份一份完整数据；点「立即备份一份」是手动备份。 自动备份保留最近若干份，手动备份单独保留同样份数、不会被随后的自动备份挤掉， 所以备份不会无限增长。下面每一条都写着里面有多少条记录、哪些教师， 恢复前先核对条数，别挑到删除之后的那份。 备份只是数据文件的副本，一条记录约 0.3 KB —— 就算录满 1 万条记录， 数据文件也只有 3 MB 左右。整个文件夹可以直接拷贝到其他电脑继续使用。

第一次打开，会碰上一个 Windows 提示

如果双击「教师请假系统.exe」时，Windows 弹出蓝色的「Windows 已保护你的电脑」， 发布者显示为「未知」——这不是病毒。原因是本软件没有购买 Windows 数字签名证书 （证书只用于消除这条提示，不影响软件功能）。本软件不联网、不上传任何数据， 记录只保存在本文件夹的 data 里。

  1. 点窗口里的「更多信息」
  2. 再点「仍要运行」

同一台电脑只需设置一次，以后双击就能直接打开。 如果把整个文件夹拷到另一台电脑，那台电脑会再问一次。
